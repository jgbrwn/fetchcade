Play from Internet Archive

Paste an Archive item page or a direct Archive file URL. CartRelay stores only the pointer; the game is fetched for this play session. Use only software you have the right to access.

Optional Archive CORS relay

Some Archive downloads redirect to storage nodes that omit browser CORS headers. Deploy the included archive-relay-worker.js, then paste its base URL here. It follows Archive redirects and streams bytes back with Cache-Control: no-store. It does not save ROMs.

What this POC proves

• Koin.js supplies the mobile virtual D-pad/buttons and emulator cores.
• Archive item pages can be resolved through the public metadata API.
• ROM bytes are fetched only when a game is launched; this app has no ROM database or upload flow.
• The included relay is a no-storage workaround for inconsistent Archive CORS redirects.
• HTTP/browser caches are outside CartRelay's control in direct mode; the relay explicitly returns no-store.
